## 🧩 About

**Frostpunk 2 overlay** is a curated list of Frostpunk 2 open-source tools:

- **Overlays** — on-screen helpers, resource layout notes, heat map viewer, city planner overlay
- **Quality-of-Life Helpers** — resource tracker notes, faction overview panel, research queue helper
- **Research Notes** — city layout studies and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 City Helpers
- Resource Overview — study stockpile and production notes
- Heat Map Viewer — visualize district heat coverage
- Build Planner — layout notes for districts and roads
- Time Control Notes — pause and review city cycles for study

### 🎨 Faction & Research
- Faction Panel — browse faction relations and votes
- Research Queue Helper — organize tech tree notes
- Law Book Notes — review enacted laws in one place

### 🏋️ Study Layout
- Scenario Notes — segment study of each scenario
- Population Tracker — overview of citizens and workers
- Event Log — review decision history in the overlay

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
